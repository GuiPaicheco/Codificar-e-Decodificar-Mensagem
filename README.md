# RSA interativo

Demonstração didática de codificação RSA com exibição passo a passo; decodificação indicada como futura na interface.

**Contexto:** Demonstração educacional.  
**Tecnologias:** HTML, CSS e JavaScript.

## Visão do projeto

A interface apresenta a codificação e os cálculos RSA passo a passo. A decodificação está marcada como futura. Use como demonstração matemática, sem finalidade de proteção de dados reais.

## Executar localmente

Clone o repositório e sirva os arquivos localmente. Com Python instalado:

```bash
git clone https://github.com/GuiPaicheco/Codificar-e-Decodificar-Mensagem.git
cd Codificar-e-Decodificar-Mensagem
python -m http.server 8000 --bind 127.0.0.1
```

Abra [http://127.0.0.1:8000/index.html](http://127.0.0.1:8000/index.html). Preserve as pastas de imagens, estilos e scripts. Recursos externos, quando usados pela página, podem exigir conexão com a internet.
